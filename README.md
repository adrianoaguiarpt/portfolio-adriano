# Adriano Aguiar — Portfólio

Website pessoal / cartão de visitas de **Adriano Aguiar**, Desenvolvedor Full Stack (Porto, Portugal).

Página única, responsiva e sem dependências de build — HTML, CSS e um pequeno ficheiro JavaScript para o menu.

## Estrutura

| Ficheiro | Função |
|----------|--------|
| `index.html` | Conteúdo e estrutura da página |
| `style.css` | Estilo (tema escuro, grid responsivo) |
| `script.js` | Alternância do menu em ecrãs pequenos |
| `img/` | Foto de perfil e favicons |

## Desenvolvimento

Não requer instalação. Abrir `index.html` no navegador ou servir a pasta:

```bash
python3 -m http.server
```
